推し道 (Oshimichi) 웹사이트

폴더 구성
- index.html: 웹사이트 시작 파일
- css/: 디자인 스타일
- js/: 동작 및 장소 데이터
- assets/: 향후 이미지 파일을 추가할 폴더

실행 방법
1. ZIP 압축을 해제합니다.
2. oshimichi_website 폴더 전체를 원하는 위치에 복사합니다.
3. index.html을 브라우저에서 엽니다.
4. 일부 지도/외부 API 기능은 인터넷 연결 또는 로컬 웹서버가 필요할 수 있습니다.
   예: 폴더에서 python -m http.server 8000 실행 후 http://localhost:8000 접속

중요: index.html만 이동하지 말고 css, js 폴더를 함께 보관하세요.
