OSHIMICHI 推し道 — GitHub Pages 업로드 안내

1. 압축을 해제합니다.
2. 폴더 안의 index.html, css, js, assets 폴더를 GitHub 저장소 최상위(root)에 올립니다.
3. Settings > Pages > Deploy from a branch > main / (root) > Save를 선택합니다.
4. index.html 파일을 열어 로컬에서도 확인할 수 있습니다. 다만 지도/외부 서비스는 인터넷 및 배포 환경이 필요할 수 있습니다.

이 버전은 oshimichi_step03_detail_fixed.html 원본을 기준으로 CSS / JS를 순서 그대로 분리했습니다.
